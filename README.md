# webdev-micro-projects

A collection of small projects built for practice and experimentation. Each folder is a standalone mini site that can be opened directly in a browser.

## Projects

- [birthday-card](https://vagish-kumar-raj.github.io/webdev-micro-projects/birthday-card/) - a simple birthday card page.
- [bussiness-card](https://vagish-kumar-raj.github.io/webdev-micro-projects/bussiness-card/) - a business card layout.
- [google-search-page](https://vagish-kumar-raj.github.io/webdev-micro-projects/google-search-page/) - a Google-style search landing page.
- [space-site](https://vagish-kumar-raj.github.io/webdev-micro-projects/space-site/) - a multi-page space travel themed site.
